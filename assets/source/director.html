WeChat Director v2.5.1

视觉导演系统：文章配图与电影感分镜流程

目标：不是说明书截图，而是为文章补上意境、情绪和视觉呼吸。

核心使命 张艺谋负责视觉导演：Flat Vector Illustration + Sticker Style。红色圆框眼镜、光头、山羊胡、白色描边是 IP 一致性锚点。
① 运行时机
推荐时机 文章定稿后（writer Stage 4 归档前） 默认输出到项目 zpicture.assets/
输入对象 已定稿文章 02_Draft.md 按段落与情绪节奏设计插图
归档后回补 必须指定 --output-dir 避免后续错误或图片错位覆盖
STEP 1 · 分镜设计张艺谋
  • 识别情绪节奏与留白处，跟随情绪转折插图
  • 不按字数机械计算；1500–2000 字通常 4–6 张
  • 输出遵循 io_schema.md 的 Markdown / Regex 结构
产出 Storyboard.md
→
STEP 2 · 出图前决策用户
  • 每次都重读 conductor/api_keys.json
  • 展示可选渠道，等待用户显式选择
  • 禁止因「只有一个 provider」就自动代选
产出 渠道已选定
→
STEP 3 · 批量执行visualize.py
  • 读取 Storyboard.md 中的 Prompt 代码块
  • 优先传 --draft：生成 → 压缩 → 传 COS → 注入正文
  • auto 顺序固定 gpt-image2 → gemini
产出 zpicture.assets/ + 正文注入
→
STEP 4 · 图片交付验收马可婷 / 用户
  • Agent / 平台出图时必做
  • 跑 validate_images.py 对齐分镜
  • 检查齐图、尺寸、比例、可读性
产出 可发布配图
② 关键节点
分镜完成必须先有 Storyboard.md
用户确认选定渠道后才执行生图
auto 回退gpt-image2 → gemini；gemini-web 须显式指定
IP 参考图IP 一致时读取 assets/IP_Reference.png
③ 三类图片规格
Part A 主视觉 2.35:1（1504×640）· movie composition · 禁止 Context 字段 · 结尾 --ar 2.35:1
Part B 侧边栏 1:1（1024×1024）· 纯色背景 · 中文 4–6 字 · 上下两行 · 禁止英文
Part C 内文配图 3:4（768×1024）· 每张必须有 Context · 锚点为上一段最后一句原文
执行链 Storyboard.md → visualize.py → 生成图片 → 压缩 → 上传 COS → 插入正文 → 原图保留在项目内
