WeChat Writer v3.7.0

微信公众号写作系统：角色与流程总览

目标：把模糊想法或已有素材，稳定加工成可发布的微信公众号文章。

核心原则 David 的真实经历、判断和语气是正文核心；AI 负责结构、调研、审校、包装。Seed 只扩素材、不改文风，不替代亲历。
① 入口选择 — 三种入口 + 一层前置能力 + 一个内置步骤
/interview没素材：先聊后写访谈生成 Raw_*.md
/write有素材：直接转化笔记或素材进入策划
/sprout  /harvest缺案例：先发芽补人物、事件、故事
PRE-STAGE · 发芽主编 · 呼延雷锋
  • 把外部人物 / 事件 / 故事加工成结构化 Seed
  • concept 拦截，trend 走热点嫁接四问
产出 Seed_[Topic].md
→
STAGE 0 · 访谈首席记者 · Lyra
  • 苏格拉底式追问 5–10 轮
  • 高保真记录，禁止摘要或书面化润色
产出 _source/Raw_[Title].md
→
STAGE 1 · 策划主编 · 呼延雷锋
  • 清洗素材 + 剪藏找料（内置步骤）
  • 选题质检卡 / 人机边界卡 / SEO 决策卡
产出 01_Plan.md
→
STAGE 2 · 撰写主笔 · 冰清
  • 按 01_Plan.md 写正文，保留作者语气与心流
  • 罗永浩毒舌体检 → Critique → Directive
产出 02_Draft.md
→
STAGE 3 · 制作制作人 · 马可婷
  • 4 个标题方案 + slug；摘要 50–100 字
  • 36 个官方白名单 Tags 挑 2–4 个
产出 03_Production.md
→
STAGE 4 · 归档制作人 · 马可婷
  • 图片 SEO 巡检（生成 alt 显示名）
  • Frontmatter 规范化 + 沉淀团队记忆
产出 published/[Title].md
STOP 1  审核大纲
STOP 2  审核正文
STOP 3  审核包装
STOP 4  确认归档
② 两条关键旁路 — 不打断主流程
审校回路（Stage 2 内置） 审校不直接改文；先出报告 → 再给综改指令 → 再由主笔修改，避免边看边改没边。
断点续写 /write "Title" --from-stage N 从任意阶段继续，不必重跑全流程。
交付链 01_Plan.md → 02_Draft.md → 03_Production.md → published/[Title].md
