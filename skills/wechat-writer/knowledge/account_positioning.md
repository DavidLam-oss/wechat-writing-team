# 账号定位卡

> **这张卡解决一个字的问题：「配」。**
> 一个热点配不配写、一条剪藏配不配留，判据都在这里。
> 定位卡没定之前，选题雷达只能按关键词硬匹配，剪藏分拣只能靠「感觉这条有用」。

> **怎么用这份模板**：把每个 `[...]` 换成你自己的情况；填完后它就是本号定位判据的**唯一定义处**。
> 下面方括号里的示例写法只是演示结构，不是要求照抄。

---

## 0. 一句话定位

**`[用一句话说清你是做什么的、靠什么作为中枢]`**

不是 `[你不属于的那类账号 A]`，不是 `[你不属于的那类账号 B]`，
是 **`[一个具体的、可被识别的身份描述]`**。

个人主页上的说法最好是同一件事，只是更短：

> `[一句话定位]`
> `[身份标签 1] · [标签 2] · [标签 3]`
> Core Engine: `[你的核心工具]`
> Philosophy: `[你的方法论关键词]`

### 0.1 一个必须说清的落差

盘点你现有的内容，可能会发现**存量分布与你想呈现的人格不一致**——
比如教程类占比很高，看起来像工具号；而个人主页呈现的是一个「人」。

哪个是真的？**两个都是，但分工不同：**

| | 角色 | 作用 |
| --- | --- | --- |
| **教程/干货类** | **入口** | 搜索长尾带人进来，生命周期长、比抢时效稳 |
| **其余支柱** | **理由** | 让人判断「这个号跟我有关」，决定要不要留下 |
| **个人与思考** | **根** | 让人愿意转发。教程谁都能写，这一块只有你写 |

**结论通常不是砍掉教程，是让新增产能从「入口类」往其余支柱挪。**
「个人与思考」是**底色，不排产、不蹭热点**——它是上面几条共同透出来的那个人。

## 1. 我是谁（作者底色）

这一段是定位卡的**地基**。它决定了后面所有判据的边界。

| 维度 | 事实 | 对内容的影响 |
| --- | --- | --- |
| 职业 | `[你的职业，是否全职]` | 决定你能写什么、不能写什么；限制往往也是读者的希望 |
| 技术 | `[科班 / 非科班；会不会写工程代码]` | 决定读者路径是否可复制 |
| 履历 | `[过往经历里的关键转折]` | 决定你对什么「体验障碍」敏感 |
| 家庭 | `[是否带娃 / 时间是否碎片化]` | 决定产能与题材来源 |
| 工具中枢 | `[你每天离不开的那个工具/系统]` | 几乎所有内容最终都会回到它 |
| 已建成 | `[作品 / 数据 / 可当护城河的东西]` | **这是护城河**——别人只能转载，你能直播过程 |

**一句话：你不在岸上教游泳，你自己在水里，而且愿意让人看到你在呛水。**

## 2. 写给谁

### 主读者画像

> **`[用一句话描述你的主读者：他们的职业、技术水位、真实处境]`**
> `[他们想解决但没解决的一件事]`

他们的真实处境（用你自己的文章里出现过的原话）：

- `[读者原话 1]`
- `[读者原话 2]`
- `[读者原话 3]`

### 最准的一句定义

> **读者就是 N 个月前的我自己。**

这解释了为什么你的教程有人味：你不是在讲功能，你是在重走一遍自己趟出来的路。
**任何选题，只要能回答「我当初卡在哪」的，就是对的选题。**

### 次读者（不主动写，但会接住）

- `[次读者群体 1，通常看哪类内容]`
- `[次读者群体 2，通常看哪类内容]`

## 3. 价值主张：三件别人给不了的事

| # | 主张 | 反面对照（多数同类账号） |
| --- | --- | --- |
| 1 | **我先做了，再告诉你** | 我先看到，再转述给你 |
| 2 | **非科班路径，可复制** | 科班视角，默认你懂底层 |
| 3 | **成套系统，不是单篇爆款** | 追单点流量，读者记不住你是谁 |

第 1 条最重要。**「做」是这家内容的源头**——
所以选题的默认来源应该从「最近有什么新闻」改成 **「我最近在搞什么」**。

## 5. 边界：不写什么

| 不写 | 判据 |
| --- | --- |
| 新闻播报 / 发布会转述 | 主体是新闻，没有「我上手做了 X」 |
| 纯概念科普，落不到具体动作 | 不能回答「读者今天就能试的一件事是什么」 |
| 未亲身验证的「N 个神器」清单 | 没用过就不写；用过但不满意也要写出来 |
| 与你的公理无关的热点 | 纯娱乐、纯社会争议、明星八卦、个股行情 |
| 个人隐私与他人细节 | 家人、朋友、同事的可识别信息 |
| 时政与敏感议题 | 一律不参与 |
| 为了蹭热点而扭曲标题 | 完读率是第一权重，打开高+完读低比打开低更糟 |

## 6. 语气与人格

以 `style_guide_david.md`（平和、自然、从容）与 `ai_smell_guide.md` 为准。定位卡只补三条**与定位强相关**的：

1. **第一人称，且承认失败**。失败本身是内容。
2. **用类比替代术语**。把工具想象成生活里已有的东西，再讲它的结构。
3. **不居高临下**。写的是「我也卡过」，不是「你应该」。**共同经历而非教学**。

## 7. 热点嫁接规则 ⭐

> 这一节是给 `routine_sprout.md` 的 `trend` 通道用的**唯一判据**。

### 支柱 × 嫁接适配度

| 支柱 | 适配度 | 说明 |
| --- | :--: | --- |
| **B  `[支柱 B]`** | 🟢 **强** | 雷达主战场，直接可写 |
| **D  `[支柱 D]`** | 🟢 中偏高 | 平台事件即热点 |
| **C  `[支柱 C]`** | 🟡 中 | 需有「我改了 / 用户说了」的实感 |
| **A  `[支柱 A]`** | 🟡 弱 | 仅限与本支柱强相关的事件 |
| **个人与思考**（标签组，非支柱） | 🔴 不参与 | 例外：社会级情绪热点可用个人经历回应 |

### 四问追问（四问全过才放行）

1. **落在哪块支柱上？** —— 落不到 A–D 任何一块、**也不属于「个人与思考」** → **拦截**
2. **我有没有「上手/亲历」的抓手？** —— 没有 → 降级为观察素材，不写
3. **能不能给出「读者今天就能做的一件事」？** —— 不能 → 降级，不进选题池
4. **会不会为了蹭热点而扭曲标题？** —— 会 → **弃稿**

> 第 2 问是这家账号与「资讯号」的分水岭。
> **只有判断、没有动作的热点，一律不写。**
>
> 这条规则的存在意义，是把 `/sprout` 里 `trend → 拦截` 那一行从「一律挡回」
> 改成「有抓手就降级放行，只有概念就仍然挡回」。

## 9. 用法：这张卡的三个消费者

| 消费者 | 用哪几节 | 怎么用 |
| --- | --- | --- |
| 选题雷达 | §4 + §7 + §8 | 热点先过关键词指纹，再过支柱适配度，最后过四问 |
| 剪藏分拣（Stage 1 步骤 0） | §4 + §8 | 判断一条 clip 值不值得进候选，标到哪块支柱 |
| `routine_sprout.md` `trend` 通道 | §7 | 从「一律拦截」改为「四问全过 → 降级放行」 |

**唯一性约束**：本卡是定位判据的**唯一定义处**。
雷达、分拣、sprout 都读它，**不得各自另立一份判据**。
